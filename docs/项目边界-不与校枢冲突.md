## 三、硬性规则

1. 不调用、不加载、不卸载 Ollama（11434）里的任何模型
2. 不停止/重启任何校枢进程
3. 不写校枢目录；不占用 19000/19100/19101
4. 需要本地模型时：自己起独立进程（独立模型文件、独立端口），GPU 冲突时用 CPU 或放弃
5. 语音：**不使用 CosyVoice2**；需要语音时另建独立 TTS（不在 MVP 范围）
6. 任何批量/夜间任务（大模型重写记忆）必须用独立实例，且机器空闲时跑

## 五、用户授权：空闲时可借 qwen3.5:9b

用户明确授权：**校枢不用 qwen3.5:9b 时，安诗鱼可以调用**。

实现：`anshiyu-server/local_llm.py`
1. 调用前查 `http://127.0.0.1:11434/api/ps`，有模型加载 → 判定"校枢在用"，直接放弃
2. 空闲才发请求，`keep_alive=30s`，用完自动卸载，显存还给校枢
3. qwen3.5:9b 是思考模型，必须 `"think": false`，否则 content 为空
4. 失败不重试、不抢占；云端（DeepSeek）仍是默认主路径，本地只做兜底
5. bge-m3 向量借调同理（`try_local_embed`），默认未启用

实测：
- 校枢占用时：`try_local_chat` 返回 None（不打扰）
- 校枢空闲时：返回正常回复「在的，摸摸头，先歇会儿。要不要我给你讲个笑话逗逗乐？」


## 六、模型分工（用户确认版）

| 用途 | 模型 | 说明 |
|---|---|---|
| 聊天/主动消息/分享配文的**内容生成** | **DeepSeek 云端** | 不走本地，避免内容质量下降 |
| **写代码**（开发任务） | **本地 qwen3.5:9b**（校枢空闲时） | 用户明确：写相关代码时交给它 |

实现：
- 内容：`app.py` 的 `ask_llm(prefer="cloud")` 默认云端
- 写代码：
  - HTTP：`POST /api/code {"instruction": "...", "context": "...", "language": "python"}`
  - 命令行：`python local_code.py "写一个..." [上下文文件]`
  - 均先查 Ollama 是否空闲；校枢占用时返回 `busy`，绝不抢占
  - qwen3.5:9b 为思考模型，已设 `think=false`

实测：
- 校枢忙时：`/api/code` 返回 `{"ok": false, "reason": "busy"}`
- 校枢空闲时：生成成功（回文函数示例）
