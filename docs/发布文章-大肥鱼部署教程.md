# 大肥鱼部署教程：在自己电脑上跑一个会生活、有记忆的 AI 伴侣（鸿蒙 + Python）

> 本文对应项目：<https://github.com/syd273/dafeiyu>（国内镜像：<http://121.196.175.68/repo/>）
> 关键词：大肥鱼部署 / 本地部署 AI 伴侣 / 鸿蒙 AI 应用 / DeepSeek 自建 / 记忆系统

---

## 这是什么

**大肥鱼** 是一个完全跑在自己电脑上的 AI 陪伴项目。它不是"套壳聊天"，而是有一套自己的生活逻辑：

- **她会生活**：有作息表（早餐、写东西、做饭、阳台看外面），每天自主产生生活事件
- **她会主动找你**：早安、晚安、关心、想念，甚至吃醋
- **她有记忆**：每句对话都会进入记忆库，带情绪权重和遗忘曲线，夜间自动巩固、写日记
- **记忆星图**：横屏 3D 银河，每颗星是一条记忆，点开能看当时说了什么

技术栈：**鸿蒙 App（ArkTS）+ Python 网关（FastAPI）+ Node 生活引擎 + Three.js 星图**，聊天走你自己的 DeepSeek API Key，数据全部落在本地。

## 部署前准备

| 项 | 要求 |
|---|---|
| 系统 | Windows 10/11（macOS/Linux 也能跑服务端，客户端需另编译） |
| Node.js | 18+ |
| Python | 3.10+ |
| DeepSeek API Key | 聊天和文案生成都靠它 |
| 鸿蒙设备 | 手机需 HarmonyOS NEXT；没有也能先用网页版测试 |
| 网络 | 手机和电脑在同一个 WiFi |

## 第一步：拉代码

```bash
git clone https://github.com/syd273/dafeiyu.git
cd dafeiyu
```

> GitHub 访问不了的话，用镜像把 `repo/` 目录整包下下来，结构是一样的。

## 第二步：一键初始化

```powershell
powershell -ExecutionPolicy Bypass -File scripts\setup.ps1
```

这个脚本会：检查 Node/Python 版本、安装 Python 依赖、初始化 `persona/` 配置模板。

## 第三步：填 API Key

在项目根目录新建 `deepseek-key.txt`，只写一行：

```
sk-你的key
```

## 第四步：启动全部服务

```powershell
powershell -ExecutionPolicy Bypass -File scripts\start_all.ps1
```

它会拉起四个进程：

| 服务 | 端口 | 作用 |
|---|---|---|
| Python 网关 | 8900 | 聊天、状态、记忆、通知的对外接口 |
| Node 生活引擎 | 8910 | 作息、情绪、主动消息、夜间巩固 |
| 记忆星图 | 8899 | 3D 星图 Web 页面 |
| 记忆同步 | — | 定时把新记忆写进星图 |

**验证是否成功**（返回 200 就对了）：

```powershell
curl http://127.0.0.1:8900/api/status
curl http://127.0.0.1:8899/
```

## 第五步：让手机连上

1. 电脑上 `ipconfig`，记下无线网卡的 IPv4（形如 `192.168.1.10`）
2. 手机装 App 后打开：**设置 → 本地服务器**，填 `http://192.168.1.10:8900`
3. 点「测试连接」→ 显示成功 → 「保存本地」

> 换 WiFi 后 IP 会变，App 内置了扫描兜底：连不上时会自动扫同网段的常见网关地址。

## 第六步：编译鸿蒙客户端（可选）

如果你只想先体验，跳过这步，直接用电脑浏览器打开 `http://127.0.0.1:8900/static/index.html` 就能聊天。

要装到手机上：

1. 用 DevEco Studio 打开 `app-harmony/`
2. 登录华为开发者账号 → 配置自动签名
3. 连手机 → 运行

命令行构建、自定义签名、以及上架自检的坑，见项目文档 `docs/鸿蒙构建与部署.md`。

## 常见问题

**Q：手机一直显示"离线 / 重连"**
A：九成是 IP 填错或不在同一 WiFi。先在电脑浏览器里试 `http://127.0.0.1:8900/api/status`，能通再查手机侧。

**Q：星图黑屏**
A：8899 没起，或者手机访问不到。新版会显示"星图服务没有连上"的提示页，不再纯黑。

**Q：冷启动特别慢（10 秒以上）**
A：这是旧版本的问题——网络不可达时在等 8 秒超时。v1.0.0 已把超时压到 1.5 秒、IP 探测收敛到 0.6 秒，冷启动降到 3 秒内。

**Q：想改她的名字**
A：设置 → 她的名字，即时生效。人设（性格、说话风格）在 `persona/persona.json`。

**Q：数据存在哪**
A：全部在本机。聊天记录在 `life-core/data/`，记忆星在 `milky-way-3d/memory_stars.json`，除了调用 DeepSeek API 之外不上传任何东西。

## 为什么值得折腾

市面上"AI 伴侣"大多是网页套壳，关掉页面就没有连续性。大肥鱼的差异在于**状态是持续的**：

早上她可能在阳台看外面，中午在做饭，晚上写日记；这些事件会进入记忆，第二天聊天时她能提起。你半个月前随口说的一句话，可能会出现在某颗星星上。

这套东西的价值不在于模型多强，而在于**它属于你**——跑在你的机器上，数据不出门，人设和记忆都可以自己改。
