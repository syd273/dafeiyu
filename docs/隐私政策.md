# 安诗鱼 · 隐私政策

> 最后更新：2026-11-11
>
> 本政策说明「安诗鱼」（以下简称"本应用"）如何处理你的信息。
> 本应用是个人自用的开源项目，不提供账号体系，不收集你的身份信息。

---

## 一、我们收集什么

本应用**不收集**：姓名、手机号、身份证号、位置、通讯录、相册（除你主动选择的图片）、设备标识。

本应用在你设备上**本地保存**以下内容：

| 数据 | 位置 | 用途 |
|---|---|---|
| 聊天记录 | 手机 App 本地存储 | 显示对话 |
| 她的记忆（情景/事实/日记） | 你的电脑 `memory/` | 让她记得你们的事 |
| 记忆星图数据 | 你的电脑 `milky-way-3d/` | 可视化记忆 |
| 你的偏好设置（名字/头像/主题/背景/表情包） | 手机 App 本地存储 | 个性化 |
| API Key | 你的电脑 `deepseek-key.txt` | 调用大模型 |
| 备份 | 你的电脑 `backups/` | 数据保护 |

---

## 二、信息如何使用

- **聊天内容**：会作为上下文发送给 **DeepSeek**（第三方大模型服务）以生成回复
- **记忆数据**：只用于本地生成上下文、星图展示、日记，不上传到我们的服务器（我们也没有服务器）
- **偏好设置**：只用于本机界面
- **API Key**：只用于调用 DeepSeek 接口

---

## 三、第三方共享

| 第三方 | 共享内容 | 目的 |
|---|---|---|
| DeepSeek（深度求索） | 聊天上下文 | 生成回复 |
| 华为推送（如启用） | 推送 token | 送达通知 |

请同时阅读 DeepSeek 的隐私政策与服务条款。

除此之外，本应用不会向任何第三方出售、出租或共享你的信息。

---

## 四、数据存储与安全

- 所有数据存储在**你自己的设备**（手机 + 电脑），我们无法访问
- API Key 文件会设置操作系统权限（仅当前用户可读）
- 备份文件包含聊天隐私，由你自行保管
- 提示：不要使用公共电脑/公共网络进行敏感对话

---

## 五、你的权利

| 权利 | 操作 |
|---|---|
| 查看 | 聊天记录、记忆记录、生活记录、说说 |
| 删除单条记忆 | 设置 → 记忆记录 → 删除（二次确认） |
| 清空聊天 | 设置 → 清空聊天记录（记忆保留） |
| 导出备份 | 设置 → 备份与导出 |
| 删除全部数据 | 删除手机 App + 删除电脑 `memory/`、`persona/`、`backups/` |

---

## 六、未成年人

- 未成年人应在监护人同意与陪同下使用
- 不要让她生成不适合未成年人的内容

---

## 七、内容与合规

- 本应用内置违法/隐私类词库过滤，但不能保证 100% 拦截
- 使用者应遵守所在地法律法规，不得用于违法用途
- AI 生成内容仅供参考，不构成事实或专业建议

---

## 八、政策变更

本政策更新时会修改"最后更新"日期。继续使用即表示同意更新后的政策。
