# 安诗鱼 · 从 0 到可用 总教程（详细版）

> 按顺序做，约 30 分钟。每步都有验证方法，出问题看第七章「故障修复」。

---

## 一、准备清单

| 需要 | 说明 |
|---|---|
| Windows 电脑 | 长期开机（她在电脑上生活） |
| 安卓 / 鸿蒙手机 | 装 App |
| DeepSeek 账号 | 生成对话（免费注册，有免费额度） |
| 同一网络 | 电脑和手机连同一个 WiFi / 手机热点 |
| 磁盘空间 | 约 500MB（代码 + 模型 + 记忆） |

---

## 二、注册 DeepSeek 开放平台（拿 API Key）

1. 浏览器打开 `https://platform.deepseek.com`
2. 注册 / 登录（手机号或邮箱，国内可直连）
3. 左侧菜单「**API keys**」→「**创建 API key**」
4. 名字随便填（如 `anshiyu`），点创建
5. 复制生成的 Key（`sk-` 开头，约 35 位）
   - ⚠️ 只显示一次，立刻存到记事本
6. 左侧「**充值**」看余额
   - 新用户一般有免费额度
   - 长期使用建议充 10-50 元（按 token 计费，很便宜）

**验证**：Key 已复制、余额 > 0。

## 三、部署后端（电脑上）

### 3.1 放项目

把整个项目放到：

```
D:\大肥鱼\
```

目录结构（关键）：

```
D:\大肥鱼\
  anshiyu-server\     网关（8900）
  life-core\          生活引擎（8910）
  milky-way-3d\       记忆星图 / 上帝视角（8899）
  persona\            人格与配置
  memory\             记忆数据
  scripts\            启动/维护脚本
  docs\               文档
```

### 3.2 安装依赖

打开 PowerShell（Win 键搜「PowerShell」），执行：

```powershell
powershell -ExecutionPolicy Bypass -File "D:\大肥鱼\scripts\setup.ps1"
```

脚本会：
- 检查 Python 3.12 / Node.js 是否安装
- 安装 Python 依赖（FastAPI、requests 等）
- 生成配置文件模板

### 3.3 填 API Key

新建/编辑：

```
D:\大肥鱼\deepseek-key.txt
```

内容只有一行：你的 `sk-...` Key（不要引号、不要换行）。

### 3.4 启动服务

```powershell
powershell -ExecutionPolicy Bypass -File "D:\大肥鱼\scripts\start_all.ps1"
```

会启动 4 个服务：

| 服务 | 端口 | 作用 |
|---|---|---|
| 网关 | 8900 | 聊天、记忆、配置接口 |
| 生活引擎 | 8910 | 她的生活/心情/记忆巩固 |
| 星图/上帝视角 | 8899 | 3D 可视化页面 |
| 记忆同步 | — | 定时同步星图数据 |

### 3.5 验证

浏览器打开：

```
http://127.0.0.1:8900/api/ping
```

返回 `{"ok": true, ...}` 即成功。

再检查端口：

```powershell
Get-NetTCPConnection -LocalPort 8900,8910,8899 -State Listen
```

三个都有就对了。

### 3.6 开机自启（已注册）

`scripts/start_all.ps1` 已注册到 HKCU 启动项，重启电脑会自动运行。验证：

```powershell
Get-ItemProperty 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Run' | Select AnshiyuServer
```

## 四、配置手机 App

### 4.1 安装

- 鸿蒙：HAP 包，`hdc install` 或 DevEco 运行
- 安卓：见 `docs/android.md`（WebView 壳方案）

### 4.2 填服务器地址

App → 设置 → 「🏠 本地服务器」→ 填：

```
http://电脑IP:8900
```

查电脑 IP：

```powershell
ipconfig
```

找 WLAN 的 IPv4，如 `192.168.43.5`。

### 4.3 填连接令牌

- 默认令牌：`anshiyu-app-2026`（本地测试够用）
- 正式使用：改 `D:\大肥鱼\anshiyu-server\config.json` 里的 `token` 为随机串（如 `anshiyu-2026-我的随机码`）
- App → 设置 → 「🔐 连接令牌」→ 填同样的值 → 保存 → 重启 App

### 4.4 填 DeepSeek Key（二选一）

| 方式 | 操作 |
|---|---|
| 电脑上（推荐） | `D:\大肥鱼\deepseek-key.txt` |
| App 里 | 设置 → 「🔑 DeepSeek API Key」→ 粘贴 → 保存 Key → 测试 Key |

### 4.5 测试

| 操作 | 预期 |
|---|---|
| 设置 → 本地服务器 → 测试连接 | 连接成功 ✓ |
| 设置 → DeepSeek API Key → 测试 Key | Key 可用 ✓ |
| 回聊天页发一条消息 | 她正常回复 |

## 六、插件与可选组件（详细）

> 原则：核心是我们做的，周边第三方你自己装。不装也能用。

### 6.1 她的房间（上帝视角 3D 模型）

**安装**：

1. 从 GitHub 下载一个等距房间模型（`.gltf`，自包含格式）
   - 推荐（MIT）：`Aubrey-Li/cozy-room`
   - 或（Apache-2.0）：`atlassian-labs/roving-office`
   - ⚠️ `AndyLow14/Tiny-Room` 无明确许可，仅个人自用
2. 重命名为 `room.gltf`，放到：

```
D:\大肥鱼\milky-way-3d\room\room.gltf
```

3. 打开 App → 设置 → 上帝视角 → 自动加载

**不装**：页面显示「房间素材未安装」，其他功能正常。
**关闭**：设置 → 功能开关 → 房间展示 → 关。

### 6.2 表情包

**安装**：

1. 下载 `dsh-meme`（MIT）的 `assets/memes/*.png`
2. 放到 `D:\大肥鱼\persona\stickers\`（保留原文件名）
3. 生成清单 `persona/stickers.json`：

```json
[
  {"id":"daily-chat","text":"适合日常对话","file":"01-daily-chat.png","tone":"日常问候"}
]
```

4. 重启网关

**不装**：她不发 `[meme:xxx]`，聊天正常。
**关闭**：设置 → 功能开关 → 表情包 → 关。

### 6.3 记忆星图（内置）

- 我们自研的 three.js 星图，随项目发布
- 想换视觉：替换 `milky-way-3d/index.html`、`main.js`、`style.css`
- 数据接口不变（`memory_stars.json`）

### 6.4 记忆模式（内置两种）

- 衰减（默认）/ 完全，设置里切换
- 想加新模式：改 `life-core/src/brain/recall.mjs` 的权重

### 6.5 服务器（本地/云端）

- App 里两套独立配置
- 云端 = 把同一套后端部署到有公网 IP 的服务器（需要自己买云服务器）
- 切换：设置 → 云端服务器 → 填地址 → 使用这个

### 6.6 第三方依赖（随项目，MIT）

| 依赖 | 用途 |
|---|---|
| three.js | 3D 渲染 |
| GLTFLoader | 加载房间模型 |
| FastAPI / uvicorn | 网关 |
| Node.js | 生活引擎 |

都是 MIT/Apache，可随项目发布（保留版权声明）。

## 七、故障修复

| 症状 | 原因 | 修复 |
|---|---|---|
| App 显示离线 | 手机和电脑不在同一网络 / IP 变了 | 点顶栏「重连」；App 会自动扫热点网段；仍不行就重填地址 |
| `测试连接` 失败 | 服务没启动 / 防火墙 | 检查 8900 端口；`start_all.ps1` 重跑；Windows 防火墙放行 |
| `测试 Key` 失败 | Key 错 / 余额不足 / 网络 | 去 platform.deepseek.com 看余额；重新生成 Key |
| 她回复「额度不足」 | DeepSeek 余额用完 | 充值 |
| 端口被占用 | 之前的进程没退 | `Get-NetTCPConnection -LocalPort 8900` 找 PID → `Stop-Process -Id PID -Force` |
| 服务起不来 | Python/Node 未装/版本低 | 装 Python 3.12 + Node 20+；重跑 setup.ps1 |
| start_all 报错乱码 | 脚本编码问题 | 用 UTF-8 BOM 保存（仓库脚本已处理） |
| 星图打不开 | 8899 没起 | `python server.py`（在 milky-way-3d 目录） |
| 上帝视角白屏 | 房间模型缺失/损坏 | 看页面提示；换 `room.gltf` |
| 收不到通知 | App 被系统回收 | 打开 App 会补消息；要彻底解决需 Push（上架流程） |
| 她说错话/重复 | 上下文或模型问题 | 清空聊天记录（记忆保留）；或调低主动频率 |
| 记忆太多/太少 | 记忆设置 | 设置 → 记忆设置：模式/遗忘速度/上限 |
| 备份恢复 | 解压覆盖 | 停服务 → 解压 zip 覆盖 → 重启 |
| 换电脑 | 迁移 | 备份 zip 拷过去解压 + 重填 Key/配置 |
| App 打不开 | 版本不匹配 | 重装 HAP；检查 `hdc install` 日志 |

### 常用命令

```powershell
# 看三个服务是否在
Get-NetTCPConnection -LocalPort 8900,8910,8899 -State Listen

# 重启全部
powershell -ExecutionPolicy Bypass -File "D:\大肥鱼\scripts\start_all.ps1"

# 看网关日志
Get-Content "D:\大肥鱼\logs\app_server.log" -Tail 30

# 看生活引擎日志
Get-Content "D:\大肥鱼\life-core\data\lc.err" -Tail 20

# 测试网关
Invoke-RestMethod "http://127.0.0.1:8900/api/ping"

# 停止网关
Get-NetTCPConnection -LocalPort 8900 -State Listen | ForEach-Object { Stop-Process -Id $_.OwningProcess -Force }
```

## 八、升级与迁移

### 升级代码

1. 备份（App 设置 → 立即备份）
2. 拉取新代码覆盖（保留 `memory/`、`persona/`、`deepseek-key.txt`）
3. 重跑 `setup.ps1`（依赖可能变）
4. 重启服务

### 迁移到新电脑

1. 旧电脑：App → 立即备份 → 得到 `anshiyu-backup-*.zip`
2. 新电脑：项目放到 `D:\大肥鱼\` → 解压备份覆盖
3. 填 `deepseek-key.txt`
4. 跑 `setup.ps1` + `start_all.ps1`
5. App 改服务器地址到新电脑 IP
