## 三、DSH 耦合情况（决定移植成本）

### dsh-feiyu
- `lib/index.js`：DSH 侧插件壳（设置 + 生物钟 + 状态 API + cookie 写入）
- 其余全部纯 Node；`llm.mjs` 直连 API；数据在 `DSH_HOME/feiyu-ai/` 下
- **耦合点仅：宿主 shell + 会话桥（B站侧塞回会话）+ 路径基于 DSH_HOME**
- 移植成本：**低~中**（把 shell 换成本地 HTTP 服务，路径换成我们自己的数据目录）

### dsh-dafeiyu-life
- 仅 4 个文件直接 import `@deepseek-ai/*`（`hostdeps.mjs`、`mcp.mjs`、`index.js` 等）
- `index.js` 516KB，是 DSH 插件主入口，含路由/设置/会话桥
- 其余 `lib/*.mjs` 基本纯 Node
- 移植成本：**中**（需要剥离 index.js 的宿主逻辑，挑选模块接入）

## 四、建议架构（A+B 结合落地）

```
鸿蒙 App / Web 上帝视角（B 层，自研）
        │  HTTP + WS
Python API 网关（我们已有 anshiyu-server，B 层）
        │  HTTP（Life Core API）
Node「Life Core」服务（A 层，抽自 feiyu/dafeiyu-life）
   ├─ brain / 记忆 / 情绪 / 人格（feiyu tools）
   ├─ 社交 / B站 / 抖音 通道（feiyu + dafeiyu-life 精选）
   └─ 直连 LLM（llm.mjs，API Key 用户自填）
        │
SQLite / JSON 数据（迁移我们已有 archive.db、memory_stars.json）
```

**Life Core API 草案**
```
GET  /state          此刻/心情/日程/兴趣
GET  /memories       记忆 + 保持度
POST /event          生活事件（刷视频/发呆/日记）
POST /chat           对话
POST /share          主动分享（B站/抖音）
WS   /stream         主动消息
GET  /health         健康检查
```
