# 交互约定（安诗鱼项目）

## 1. 本地 vs 云端：必须让用户选

**规则**：当任务在"本地模型能力 ≈ 云端模型能力"的区间内时，**不要自己决定**，先问用户：
「这件事用本地模型还是云端？」，按用户选择执行。

适用场景（举例）：
- 写一段代码 / 改一个函数
- 短文案、总结、分类
- 简单问答、格式转换

不适用（直接走云端或直接走本地）：
- 明确超出本地能力（长上下文、复杂推理）→ 云端
- 明确只有本地能做（离线、隐私、GPU 空闲）→ 本地，但说明原因

## 2. 已授权事项

- 本地模型借调：**校枢空闲时**可调用 Ollama（qwen3.5:9b 已授权；其余待确认）
- 写代码任务：可交给本地模型（qwen2.5-coder:7b 待确认替换）
- 内容生成（聊天/主动消息/分享）：默认 DeepSeek 云端

## 3. 禁止事项

- 不干扰校枢：CosyVoice2(19100)、XiaoShuApp、19000、19101 一律不碰
- 不调用/不卸载正在被使用的 Ollama 模型
- 本地借调前必须查 `/api/ps` 空闲；keep_alive 短；用完释放

## 4. 待确认

- ✅ 已确认（2026-11-09）：**App 实时聊天 = 云端优先**；云端失败才切本地（校枢空闲时）
- 开发任务（写代码/短文案等两边都能做）：仍然每次问用户

详见 `docs/开发铁律.md`。
