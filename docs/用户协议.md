## 一、服务说明

「安诗鱼」是一款**个人自用**的 AI 陪伴应用：

- 由一个手机 App + 一个电脑端服务组成
- 服务端运行在你自己的电脑上，数据存在你自己的设备
- 她的对话由第三方大模型（DeepSeek）生成
- 本应用不提供账号注册、不提供云端存储、不提供付费服务

---

## 二、使用资格

- 你应具备完全民事行为能力
- 未成年人应在监护人同意与陪同下使用
- 你应自行准备：一台电脑（运行服务端）、一部手机、DeepSeek API Key、网络
