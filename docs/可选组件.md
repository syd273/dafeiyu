# 可选组件（不属于本项目，自行安装）

安诗鱼的设计原则：**核心是我们做的，周边是可替换的。** 以下组件不属于本项目，默认不随仓库发布，需要时自行安装。

---

## 1. 她的房间（上帝视角 3D 模型）

「上帝视角」页面默认**不内置房间模型**，缺少时页面会提示"房间素材未安装"。

### 安装方式

1. 从 GitHub 下载一个等距 3D 房间模型（`.gltf` 自包含格式）
2. 放到：

```
milky-way-3d/room/room.gltf
```

3. 刷新「上帝视角」即可

### 推荐素材（自行选择，注意许可）

| 项目 | 许可 | 说明 |
|---|---|---|
| [AndyLow14/Tiny-Room](https://github.com/AndyLow14/Tiny-Room) | ⚠️ 无明确许可 | 等距卧室，个人自用可以，**不建议随项目分发** |
| [Aubrey-Li/cozy-room](https://github.com/Aubrey-Li/cozy-room) | MIT | 温馨房间 + 昼夜循环，可开源分发 |
| [atlassian-labs/roving-office](https://github.com/atlassian-labs/roving-office) | Apache-2.0 | 办公室场景，AI agent 在房间走动 |

> 你选哪个都行，只要把 `room.gltf` 放对位置，页面会自己加载。

## 2. 表情包（她发聊天表情）

默认**不内置**第三方表情包。

### 安装方式

1. 从 [dsh-meme](https://github.com/omdsh-dev/dsh-meme)（MIT）下载 `assets/memes/*.png`
2. 放到 `persona/stickers/`（文件名如 `01-daily-chat.png`）
3. 在 `persona/stickers.json` 里登记（或参考 dsh-meme 的 `catalog.ts`）

> 没有表情包时，她不会发 `[meme:xxx]`，聊天不受影响。

---

## 3. 记忆模式

内置两种，可在 App「设置 → 记忆设置」切换：

- **衰减**：按艾宾浩斯曲线遗忘（默认）
- **完全**：不遗忘、全量召回

扩展：想加"只记重要的事""按情绪加权"等模式，改 `life-core/src/brain/recall.mjs` 的权重即可。

---

## 4. 记忆星图

内置 three.js 星图场景（`milky-way-3d/`），是我们自己写的，随项目发布。

想换视觉效果：替换 `milky-way-3d/index.html`、`main.js`、`style.css` 即可，数据接口不变（`memory_stars.json`）。

---

## 5. 服务器（本地 / 云端）

App「设置 → 服务器」里两套独立配置：

- **本地**：电脑跑网关（默认，零成本）
- **云端**：自己的云服务器跑同一套服务（需要公网 IP）

两者接口一致，App 里切换即可，不需要改代码。
