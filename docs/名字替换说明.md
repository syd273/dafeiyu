# 名字替换说明

**安诗鱼** 和 **大肥鱼** 是同一个项目的两个名字，可自由互换。

## 把「安诗鱼」改成你的名字（如「我的大肥鱼」）

| 位置 | 操作 |
|---|---|
| App 显示名 | 设置 → 她的名字 → 改成「我的大肥鱼」 |
| 她的人设 | 编辑 `persona/persona.json` 里的名字/称呼/性格 |
| 应用名 | 二次开发：改 `AppScope/app.json5` 的 `label` 与媒体资源 |
| 包名 | 二次开发：改 `bundleName`（需重新签名/上架） |
| 文档 | 全局替换「安诗鱼」即可 |

## 说明

- 名字只影响显示和称呼，不影响记忆、星图、生活等功能
- 改完 App 名字后重启 App；改人设后重启网关（8900）
- 「大肥鱼」是项目早期的名字，代码和文档里偶尔还会出现，可按同样方式替换

## 如果你要做成自己的版本

1. Fork 本项目
2. 按上表替换名字
3. 修改 `persona/persona.json` 的性格描述
4. 换成自己的图标
5. 部署、上架（见 docs/上架材料.md）

这就是「属于自己的大肥鱼」。
