## 三、详细描述

```
安诗鱼是一个有"生活感"的 AI 陪伴应用。

【她会记住你】
每一次聊天都会沉淀成她的记忆：你说过的话、你的喜好、你们之间的约定。
记忆会像人一样逐渐淡化，也会在重要的事上更深刻。

【她有自己的生活】
她会自己刷视频、发说说、在房间里忙碌、夜里整理记忆。
你可以通过"上帝视角"看到她此刻在做什么。

【记忆星图】
她的每一段记忆都是一颗星，横屏查看整片星河，可以搜索、点击、删改。

【聊天体验】
文字、图片、表情包、一起听歌、说说动态，像和一个真实的人在聊天。

【本地优先】
她的记忆和聊天记录都保存在你自己的设备上，不上传云端。

说明：本应用是客户端工具，需配合你自己的服务端使用；对话能力需用户自行配置大模型 API。
```

## 八、审核说明模板（关键，直接复制）

```
【应用说明】
本应用是个人 AI 陪伴客户端工具，不内置任何大模型 API Key，不向用户提供 AI 服务。
用户需自行配置自己的服务端与大模型 API（如 DeepSeek），AI 能力由用户与模型服务商直接完成。

【功能说明】
- 聊天：与 AI 角色对话（文字/图片/表情）
- 记忆：本地记录对话要点并可视化（星图）
- 生活：角色自主发说说、展示虚拟生活状态（上帝视角）
- 全部数据仅存用户本地设备

【审核体验方式】
应用内置"演示模式"：未连接服务端时自动展示示例对话与界面，无需配置即可体验。
（演示模式为静态示例数据，不涉及真实 AI 服务）

【内容安全】
- 内置违法/隐私词库过滤（赌博、毒品、隐私查询等）
- AI 生成内容标注「AI 生成」
- 用户协议明确禁止违法用途
- 提供隐私政策与用户协议（链接见上）
```
