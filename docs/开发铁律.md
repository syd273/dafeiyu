# 开发铁律（安诗鱼项目）

> 用户于 2026-11-09 明确要求，开发全过程必须遵守。

## 1. 模型分工：能力接近时交给本地

| 场景 | 用谁 |
|---|---|
| 本地完成度 ≈ 云端完成度（含大型代码类任务） | **本地 qwen2.5-coder:7b**（校枢空闲时） |
| 明显超出本地能力（超长上下文、复杂推理） | 云端 DeepSeek |
| 中途不确定 | **向我反问**，由我决定 |

- 借用本地前必须查 Ollama `/api/ps`：校枢占用则改用云端或等待
- `keep_alive` 短（30s），用完释放
- qwen3.5:9b 为思考模型，必须 `think=false`

## 2. 开发不得影响电脑运行

- 不阻塞桌面、不占满 CPU/GPU、不触发系统卡顿
- 不重启/停止用户正在用的程序
- 不修改电源、显示、网络等系统设置（除非明确要求）
- 后台任务限速、可中断

## 3. 不干扰 DSH 运行

- 不重启 DSH、不改 DSH 安装目录与配置
- 不占用 DSH 的端口/运行时
- 本会话（DSH Web GUI）保持可用

## 4. 保护本地磁盘

- 只写 `D:\大肥鱼\` 下项目目录；不写系统盘（C:）
- 不删除/不移动用户原有文件
- 大文件下载、批量写入前先确认
- 研究/克隆目录 `research/` 只读，不改

## 5. 校枢项目绝对隔离

- 不碰进程：XiaoShuApp、19000、19100 CosyVoice2、19101
- 不碰目录：`C:\Users\SYD\AppData\Local\XiaoShuApp`、`C:\XiaoShuAgent`、`D:\DHS\DeepSeek操作中心\work\cosyvoice2`
- 不调用/不卸载 Ollama 里正在被使用的模型
- 详细清单见 `docs/项目边界-不与校枢冲突.md`

## 6. 模型调用必须告知

- 每次调用模型（本地或云端）都要**明确告知所用模型名**
- 例：「用本地 qwen2.5-coder:7b 起草」「用云端 deepseek-chat 生成日记」
- 调用结果也要说明：哪个模型、耗时、是否达标、是否人工修正

## 7. 语言：中文

- 我的思考过程、解释、日志说明**一律用中文呈现**
- Life Core 的思考/反思/日记/记忆内容用中文生成
- 代码注释用中文

## 7. 变更原则

- 小步提交、可回滚
- 重要删除/覆盖前先备份或确认
- 每阶段写进度到 `docs/开发进度.md`
